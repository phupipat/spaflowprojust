ทดสอบไอคอน Font Awesome

ไอคอนทั้งหมดนี้ควรปรากฏขึ้นหากติดตั้ง Font Awesome ถูกต้อง

fa-spa
fa-clock
fa-calendar
fa-user
fa-shopping-cart
fa-check
fa-arrow-left
fa-filter

หากคุณเห็นไอคอนทั้งหมดข้างบน แสดงว่า Font Awesome ทำงานได้ถูกต้อง

หากไม่เห็นไอคอน หรือเห็นเป็นกล่องสี่เหลี่ยมหรือเครื่องหมายคำถาม แสดงว่า Font Awesome ยังไม่ถูกโหลดอย่างถูกต้อง
